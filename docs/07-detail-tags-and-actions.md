# Словарь конкретных деталей и действий для WAI Illustrious

Практический словарь для `waiIllustriousSDXL_v170.safetensors` в Stable Diffusion WebUI Forge. Здесь не общие стили вроде «красивый рендер», а **маленькие управляемые детали**: слегка приоткрытые губы, выбившаяся прядь, положение пальцев, жесты кисти, направление взгляда и положение конечностей.

> **Важно:** английские теги ниже — отправные точки, а не гарантированные команды. Наиболее надёжно обычно работают распространённые теги из экосистемы Danbooru. Описательные сочетания вроде `loose hair strand` могут сработать слабее, потому что это не обязательно отдельный обучающий тег. Проверяй по одному изменению.

## Как читать словарь

- **Базовый тег** — с него лучше начать.
- **Уточнение** — добавляй только если базового тега недостаточно.
- **Negative** — используй только при реально наблюдаемой проблеме. Не вставляй весь словарь в каждый промпт.
- Теги действий лучше ставить рядом: сначала действие, затем уточнение позы. Например: `holding cup, fingers wrapped around cup`.

## 1. Рот и губы: от едва приоткрытых до выражения эмоции

| Что хочешь увидеть | Positive-тег | Что он обычно означает |
|---|---|---|
| Губы слегка приоткрыты | `parted lips` | Рот немного открыт; зубы могут не быть видны |
| Рот заметно открыт | `open mouth` | Более широкое открытие рта |
| Рот закрыт | `closed mouth` | Губы сомкнуты |
| Небольшая улыбка | `smile` | Улыбка; степень зависит от контекста |
| Улыбка с закрытым ртом | `closed-mouth smile` | Попробуй как уточнение, если обычная улыбка показывает зубы |
| Улыбка с зубами | `teeth, smile` | Зубы видны в улыбке |
| Надутые губы / недовольное выражение | `pout` | Надутые губы, часто недовольство |
| Прикусывает нижнюю губу | `lip bite` | Попробуй для жеста прикусывания губы |
| Дрожащие губы | `quivering lips` | Описательный тег; результат может быть нестабильным |
| Уголки рта опущены | `frown` | Хмурое или печальное выражение, не точный контроль уголков |
| Покраснение щёк | `blush` | Румянец; не заменяет тег формы рта |
| Язык виден | `tongue out` | Язык высунут; это заметно меняет выражение |

### Готовые сочетания для рта

**Спокойное, слегка задумчивое выражение**
```text
parted lips, relaxed expression
```

**Едва заметная улыбка**
```text
parted lips, slight smile
```

**Удивление**
```text
open mouth, surprised
```

**Не путай эти два тега:** `parted lips` — именно слегка разомкнутые губы; `open mouth` чаще задаёт более открытый рот. Если рот раскрывается слишком сильно, удали `open mouth` и оставь `parted lips`.

## 2. Пальцы и кисти: укажи, ЧТО делает рука

Самый полезный принцип: **сначала назови действие кисти**, а уже потом уточняй пальцы. Абстрактное `beautiful hands` почти не сообщает модели, какую позу нужно нарисовать.

| Жест / действие | Positive-теги для теста |
|---|---|
| Указательный палец поднят | `index finger raised` |
| Указывает на что-то | `pointing`, `pointing finger` |
| Знак V / ✌ | `peace sign` |
| Большой палец вверх | `thumbs up` |
| Жест «ОК» | `ok sign` |
| Машет рукой | `waving` |
| Рука у губ | `finger to mouth` |
| Палец у подбородка, задумчиво | `hand on chin` |
| Пальцы касаются щеки | `hand on own cheek` |
| Руки на бёдрах | `hands on hips` |
| Руки в карманах | `hands in pockets` |
| Руки за спиной | `arms behind back` |
| Ладони соединены | `hands together` |
| Пальцы переплетены | `interlocked fingers` |
| Руки сложены / скрещены на груди | `crossed arms` |
| Держит предмет | `holding` + название предмета |
| Сжимает кулак | `clenched hand`, `fist` |
| Рука расслаблена | `relaxed hand` — описательное уточнение |
| Пальцы растопырены | `spread fingers` — может потребовать теста |
| Рука тянется к зрителю | `reaching towards viewer` |
| Две руки формируют сердечко | `heart hands` |

### Примеры, которые можно сразу копировать

**Указательный палец поднят**
```text
raised hand, index finger raised
```

**Указывает в сторону**
```text
pointing, pointing finger, outstretched arm
```

**Пальцы держат чашку**
```text
holding cup, hand around cup
```

**Пальцы касаются губ**
```text
finger to mouth, parted lips
```

**Ладонь раскрыта**
```text
open hand, spread fingers
```

**Пальцы переплетены перед собой**
```text
hands together, interlocked fingers
```

**Важно про точность:** если написать `five fingers`, модель всё равно может нарисовать неверное число или соединить пальцы. Описание знакомого жеста (`peace sign`, `thumbs up`, `holding cup`) часто полезнее, потому что это конкретная поза, которую модель могла видеть в обучающих примерах.

### Если пальцы испорчены

Сначала проверь, достаточно ли крупно показана кисть. Если она занимает всего 20 пикселей, промпт может не спасти детали. Затем попробуй короткий negative:

```text
bad hands, fused fingers, extra digits, missing fingers
```

Не добавляй одновременно десять отрицаний. Если жест правильный, но кисть всё ещё испорчена, попробуй inpainting кисти с тем же описанием жеста.

## 3. Волосы: одна выбившаяся прядь, пряди у лица и движение

Здесь особенно важно различать **конкретный тег причёски** и свободное описание. Для заметной торчащей пряди часто стоит проверить `ahoge`. Это характерная одиночная торчащая прядь, обычно на макушке; она не означает любую случайно выбившуюся прядь сбоку.

| Что хочешь увидеть | Positive-тег / сочетание | Примечание |
|---|---|---|
| Одна торчащая прядь на макушке | `ahoge` | Самый узнаваемый тег для «антенны» волос |
| Пряди обрамляют лицо | `sidelocks` | Длинные пряди по бокам лица |
| Волосы проходят между глазами | `hair between eyes` | Пряди попадают в промежуток между глазами |
| Волосы закрывают один глаз | `hair over one eye` | Это уже сильное перекрытие глаза |
| Волосы зачесаны за ухо | `hair behind ear` | Уточняет положение волос |
| Волосы лежат на плече | `hair over shoulder` | Пряди перекинуты через плечо |
| Волосы развеваются | `blowing hair` или `wind` | Движение обычно затрагивает несколько прядей |
| Отдельная свободная прядь у щеки | `loose hair strand near cheek` | Описательная фраза, не гарантированный канонический тег |
| Несколько тонких прядей выбились из причёски | `loose hair strands, messy hair` | Может сделать всю причёску растрёпанной |
| Тонкие отдельные пряди видны | `hair strands` | Общее уточнение, эффект зависит от кадра |

### Примеры для волос

**Одна характерная прядь торчит вверх**
```text
ahoge, long hair
```

**Одна свободная прядь у щеки, причёска в остальном аккуратная**
```text
neat hairstyle, loose hair strand near cheek
```

**Две боковые пряди обрамляют лицо**
```text
sidelocks, hair framing face
```

**Ветер уносит несколько прядей в сторону**
```text
wind, blowing hair, hair strands
```

**Аккуратная причёска с несколькими выбившимися волосками**
```text
neat hairstyle, a few loose hair strands
```

Последние сочетания — описательные эксперименты, а не обещание, что модель нарисует ровно одну прядь. Если она постоянно растрёпывает всю причёску, убери `messy hair` и попробуй только `neat hairstyle, loose hair strand near cheek`. Если нужна именно одна локальная прядь, проще всего исправить её inpainting-маской.


## 11. Как собирать промпт, чтобы теги не мешали друг другу

Используй эту схему:

```text
[качество], [персонаж], [внешность], [главное действие],
[выражение лица], [деталь руки или волос], [одежда], [фон]
```

Пример:

```text
masterpiece, best quality, amazing quality, 1girl, solo,
long hair, neat hairstyle, loose hair strand near cheek,
parted lips, looking at viewer, raised hand, index finger raised,
soft lighting, detailed background
```

Это только тестовый пример: если деталей слишком много, убирай второстепенные, а не добавляй новые.

### Правило одного изменения

1. Зафиксируй seed и остальные настройки Forge.
2. Сгенерируй базовый вариант.
3. Добавь только `parted lips` и сравни.
4. Вернись к базе и отдельно проверь `loose hair strand near cheek`.
5. Затем отдельно проверь жест руки.
6. Только после этого объединяй удачные теги.

Так ты поймёшь, что именно работает на твоём экземпляре WAI.

## 12. Если точная мелочь не получается

Промпт влияет на всю композицию, а не всегда на одну конкретную прядь или палец. Если всё остальное уже получилось:

1. Открой картинку в режиме inpainting.
2. Замаскируй только нужную область — например, небольшой участок у щеки или кисть.
3. Используй короткий промпт для этой детали.
4. Не меняй одновременно лицо, причёску, позу и стиль.
5. Если деталь всё равно не слушается, попробуй другой seed или контроль позы для сложного жеста.

## 13. Возрастное впечатление: сделать персонажа визуально взрослым

Если персонаж выглядит слишком юным, одного negative prompt часто недостаточно. Лучше одновременно описать желаемый взрослый образ в positive и убрать нежелательные детские признаки в negative.

### Positive: выбрать нужный возрастной образ

| Что нужно | Positive-теги для теста | Примечание |
|---|---|---|
| Молодая взрослая женщина | `adult woman, young adult` | Взрослый персонаж с молодым лицом |
| Более зрелый женский образ | `adult woman, mature female` | Начни с этой короткой комбинации |
| Более зрелые черты лица | `mature face, defined jawline` | Может сделать лицо менее детским |
| Более взрослые пропорции | `adult proportions, longer limbs` | Описательное уточнение, не гарантия |
| Женщина средних лет | `middle-aged woman, mature face` | Более заметное возрастное впечатление |
| Пожилая женщина | `elderly woman, wrinkles, gray hair` | Используй только если действительно нужно состарить персонажа |
| Взрослый мужчина | `adult man, mature male` | Прямое указание на взрослого персонажа |
| Более зрелые мужские черты | `mature face, defined jawline` | Растительность на лице добавляй отдельно, если нужна |

**Базовый вариант для молодой взрослой женщины:**

```text
adult woman, young adult, mature female
```

Если лицо всё ещё выглядит детским, добавь один уточняющий тег:

```text
adult woman, mature female, mature face, defined jawline
```

Не добавляй `wrinkles`, `elderly` и `gray hair`, если хочешь лишь взрослую женщину, а не пожилую.

### Negative: убрать детское впечатление

Попробуй короткий блок:

```text
child, toddler, little girl, childlike face, childish features, chibi
```

- `child`, `toddler`, `little girl` — прямые указания на ребёнка; добавляй их в negative, если модель ошибочно делает персонажа ребёнком.
- `childlike face`, `childish features` — описательные подсказки против детских черт лица.
- `chibi` — карикатурно-маленькие пропорции; может давать детское впечатление, хотя это не синоним ребёнка.
- Не добавляй `young` в negative автоматически, если нужен молодой взрослый персонаж: это может конфликтовать с желаемым образом.

### Готовые блоки

**Молодая взрослая женщина**

Positive:
```text
adult woman, young adult, mature female
```

Negative:
