# Словарь конкретных деталей и действий для WAI Illustrious

Практический словарь для `waiIllustriousSDXL_v170.safetensors` в Stable Diffusion WebUI Forge. Здесь не общие стили вроде «красивый рендер», а **маленькие управляемые детали**: слегка приоткрытые губы, выбившаяся прядь, положение пальцев, жесты кисти, направление взгляда и положение конечностей.

> **Важно:** английские теги ниже — отправные точки, а не гарантированные команды. Наиболее надёжно обычно работают распространённые теги из экосистемы Danbooru. Описательные сочетания вроде `loose hair strand` могут сработать слабее, потому что это не обязательно отдельный обучающий тег. Проверяй по одному изменению.

## Как читать словарь

- **Базовый тег** — с него лучше начать.
- **Уточнение** — добавляй только если базового тега недостаточно.
- **Negative** — используй только при реально наблюдаемой проблеме. Не вставляй весь словарь в каждый промпт.
- Теги действий лучше ставить рядом: сначала действие, затем уточнение позы. Например: `holding cup, fingers wrapped around cup`.

## 1. Рот и губы: от едва приоткрытых до выражения эмоции

| Что хочешь увидеть | Positive-тег | Что он обычно означает |
|---|---|---|
| Губы слегка приоткрыты | `parted lips` | Рот немного открыт; зубы могут не быть видны |
| Рот заметно открыт | `open mouth` | Более широкое открытие рта |
| Рот закрыт | `closed mouth` | Губы сомкнуты |
| Небольшая улыбка | `smile` | Улыбка; степень зависит от контекста |
| Улыбка с закрытым ртом | `closed-mouth smile` | Попробуй как уточнение, если обычная улыбка показывает зубы |
| Улыбка с зубами | `teeth, smile` | Зубы видны в улыбке |
| Надутые губы / недовольное выражение | `pout` | Надутые губы, часто недовольство |
| Прикусывает нижнюю губу | `lip bite` | Попробуй для жеста прикусывания губы |
| Дрожащие губы | `quivering lips` | Описательный тег; результат может быть нестабильным |
| Уголки рта опущены | `frown` | Хмурое или печальное выражение, не точный контроль уголков |
| Покраснение щёк | `blush` | Румянец; не заменяет тег формы рта |
| Язык виден | `tongue out` | Язык высунут; это заметно меняет выражение |

### Готовые сочетания для рта

**Спокойное, слегка задумчивое выражение**
```text
parted lips, relaxed expression
```

**Едва заметная улыбка**
```text
parted lips, slight smile
```

**Удивление**
```text
open mouth, surprised
```

**Не путай эти два тега:** `parted lips` — именно слегка разомкнутые губы; `open mouth` чаще задаёт более открытый рот. Если рот раскрывается слишком сильно, удали `open mouth` и оставь `parted lips`.

## 2. Пальцы и кисти: укажи, ЧТО делает рука

Самый полезный принцип: **сначала назови действие кисти**, а уже потом уточняй пальцы. Абстрактное `beautiful hands` почти не сообщает модели, какую позу нужно нарисовать.

| Жест / действие | Positive-теги для теста |
|---|---|
| Указательный палец поднят | `index finger raised` |
| Указывает на что-то | `pointing`, `pointing finger` |
| Знак V / ✌ | `peace sign` |
| Большой палец вверх | `thumbs up` |
| Жест «ОК» | `ok sign` |
| Машет рукой | `waving` |
| Рука у губ | `finger to mouth` |
| Палец у подбородка, задумчиво | `hand on chin` |
| Пальцы касаются щеки | `hand on own cheek` |
| Руки на бёдрах | `hands on hips` |
| Руки в карманах | `hands in pockets` |
| Руки за спиной | `arms behind back` |
| Ладони соединены | `hands together` |
| Пальцы переплетены | `interlocked fingers` |
| Руки сложены / скрещены на груди | `crossed arms` |
| Держит предмет | `holding` + название предмета |
| Сжимает кулак | `clenched hand`, `fist` |
| Рука расслаблена | `relaxed hand` — описательное уточнение |
| Пальцы растопырены | `spread fingers` — может потребовать теста |
| Рука тянется к зрителю | `reaching towards viewer` |
| Две руки формируют сердечко | `heart hands` |

### Примеры, которые можно сразу копировать

**Указательный палец поднят**
```text
raised hand, index finger raised
```

**Указывает в сторону**
```text
pointing, pointing finger, outstretched arm
```

**Пальцы держат чашку**
```text
holding cup, hand around cup
```

**Пальцы касаются губ**
```text
finger to mouth, parted lips
```

**Ладонь раскрыта**
```text
open hand, spread fingers
```

**Пальцы переплетены перед собой**
```text
hands together, interlocked fingers
```

**Важно про точность:** если написать `five fingers`, модель всё равно может нарисовать неверное число или соединить пальцы. Описание знакомого жеста (`peace sign`, `thumbs up`, `holding cup`) часто полезнее, потому что это конкретная поза, которую модель могла видеть в обучающих примерах.

### Если пальцы испорчены

Сначала проверь, достаточно ли крупно показана кисть. Если она занимает всего 20 пикселей, промпт может не спасти детали. Затем попробуй короткий negative:

```text
bad hands, fused fingers, extra digits, missing fingers
```

Не добавляй одновременно десять отрицаний. Если жест правильный, но кисть всё ещё испорчена, попробуй inpainting кисти с тем же описанием жеста.

## 3. Волосы: одна выбившаяся прядь, пряди у лица и движение

Здесь особенно важно различать **конкретный тег причёски** и свободное описание. Для заметной торчащей пряди часто стоит проверить `ahoge`. Это характерная одиночная торчащая прядь, обычно на макушке; она не означает любую случайно выбившуюся прядь сбоку.

| Что хочешь увидеть | Positive-тег / сочетание | Примечание |
|---|---|---|
| Одна торчащая прядь на макушке | `ahoge` | Самый узнаваемый тег для «антенны» волос |
| Пряди обрамляют лицо | `sidelocks` | Длинные пряди по бокам лица |
| Волосы проходят между глазами | `hair between eyes` | Пряди попадают в промежуток между глазами |
| Волосы закрывают один глаз | `hair over one eye` | Это уже сильное перекрытие глаза |
| Волосы зачесаны за ухо | `hair behind ear` | Уточняет положение волос |
| Волосы лежат на плече | `hair over shoulder` | Пряди перекинуты через плечо |
| Волосы развеваются | `blowing hair` или `wind` | Движение обычно затрагивает несколько прядей |
| Отдельная свободная прядь у щеки | `loose hair strand near cheek` | Описательная фраза, не гарантированный канонический тег |
| Несколько тонких прядей выбились из причёски | `loose hair strands, messy hair` | Может сделать всю причёску растрёпанной |
| Тонкие отдельные пряди видны | `hair strands` | Общее уточнение, эффект зависит от кадра |

### Примеры для волос

**Одна характерная прядь торчит вверх**
```text
ahoge, long hair
```

**Одна свободная прядь у щеки, причёска в остальном аккуратная**
```text
neat hairstyle, loose hair strand near cheek
```

**Две боковые пряди обрамляют лицо**
```text
sidelocks, hair framing face
```

**Ветер уносит несколько прядей в сторону**
```text
wind, blowing hair, hair strands
```

**Аккуратная причёска с несколькими выбившимися волосками**
```text
neat hairstyle, a few loose hair strands
```

Последние сочетания — описательные эксперименты, а не обещание, что модель нарисует ровно одну прядь. Если она постоянно растрёпывает всю причёску, убери `messy hair` и попробуй только `neat hairstyle, loose hair strand near cheek`. Если нужна именно одна локальная прядь, проще всего исправить её inpainting-маской.


## 11. Как собирать промпт, чтобы теги не мешали друг другу

Используй эту схему:

```text
[качество], [персонаж], [внешность], [главное действие],
[выражение лица], [деталь руки или волос], [одежда], [фон]
```

Пример:

```text
masterpiece, best quality, amazing quality, 1girl, solo,
long hair, neat hairstyle, loose hair strand near cheek,
parted lips, looking at viewer, raised hand, index finger raised,
soft lighting, detailed background
```

Это только тестовый пример: если деталей слишком много, убирай второстепенные, а не добавляй новые.

### Правило одного изменения

1. Зафиксируй seed и остальные настройки Forge.
2. Сгенерируй базовый вариант.
3. Добавь только `parted lips` и сравни.
4. Вернись к базе и отдельно проверь `loose hair strand near cheek`.
5. Затем отдельно проверь жест руки.
6. Только после этого объединяй удачные теги.

Так ты поймёшь, что именно работает на твоём экземпляре WAI.

## 12. Если точная мелочь не получается

Промпт влияет на всю композицию, а не всегда на одну конкретную прядь или палец. Если всё остальное уже получилось:

1. Открой картинку в режиме inpainting.
2. Замаскируй только нужную область — например, небольшой участок у щеки или кисть.
3. Используй короткий промпт для этой детали.
4. Не меняй одновременно лицо, причёску, позу и стиль.
5. Если деталь всё равно не слушается, попробуй другой seed или контроль позы для сложного жеста.

## 13. Возрастное впечатление: сделать персонажа визуально взрослым

Если персонаж выглядит слишком юным, одного negative prompt часто недостаточно. Лучше одновременно описать желаемый взрослый образ в positive и убрать нежелательные детские признаки в negative.

### Positive: выбрать нужный возрастной образ

| Что нужно | Positive-теги для теста | Примечание |
|---|---|---|
| Молодая взрослая женщина | `adult woman, young adult` | Взрослый персонаж с молодым лицом |
| Более зрелый женский образ | `adult woman, mature female` | Начни с этой короткой комбинации |
| Более зрелые черты лица | `mature face, defined jawline` | Может сделать лицо менее детским |
| Более взрослые пропорции | `adult proportions, longer limbs` | Описательное уточнение, не гарантия |
| Женщина средних лет | `middle-aged woman, mature face` | Более заметное возрастное впечатление |
| Пожилая женщина | `elderly woman, wrinkles, gray hair` | Используй только если действительно нужно состарить персонажа |
| Взрослый мужчина | `adult man, mature male` | Прямое указание на взрослого персонажа |
| Более зрелые мужские черты | `mature face, defined jawline` | Растительность на лице добавляй отдельно, если нужна |

**Базовый вариант для молодой взрослой женщины:**

```text
adult woman, young adult, mature female
```

Если лицо всё ещё выглядит детским, добавь один уточняющий тег:

```text
adult woman, mature female, mature face, defined jawline
```

Не добавляй `wrinkles`, `elderly` и `gray hair`, если хочешь лишь взрослую женщину, а не пожилую.

### Negative: убрать детское впечатление

Попробуй короткий блок:

```text
child, toddler, little girl, childlike face, childish features, chibi
```

- `child`, `toddler`, `little girl` — прямые указания на ребёнка; добавляй их в negative, если модель ошибочно делает персонажа ребёнком.
- `childlike face`, `childish features` — описательные подсказки против детских черт лица.
- `chibi` — карикатурно-маленькие пропорции; может давать детское впечатление, хотя это не синоним ребёнка.
- Не добавляй `young` в negative автоматически, если нужен молодой взрослый персонаж: это может конфликтовать с желаемым образом.

### Готовые блоки

**Молодая взрослая женщина**

Positive:
```text
adult woman, young adult, mature female
```

Negative:
```text
child, toddler, little girl, childlike face, childish features, chibi
```

### Если модель всё равно делает лицо слишком юным

1. Зафиксируй seed и настройки Forge.
2. Добавь только `adult woman, mature female` или `adult man, mature male`.
3. Если этого мало, проверь `mature face` или `defined jawline` по одному.
4. Проверь, не задают ли другие теги карикатурные или детские пропорции.
5. Если лицо уже получилось, а нужно поправить только его возрастное впечатление, попробуй локальный inpainting.

**Оговорка:** это практические кандидаты для тестирования, а не гарантированный возрастной фильтр. У разных персонажей и seed эффект может различаться.

## 14. Пропорции тела и черты лица: универсальная база и варианты

Этот раздел нужен, чтобы задавать **форму и относительные размеры**, а не надеяться на слово `beautiful`. Не добавляй все теги подряд: выбери один базовый вариант телосложения, а затем уточни только те части, которые действительно хочешь изменить.

### 14.1. Универсальная база: сбалансированное взрослое тело

Начни с этого короткого блока, если хочешь избежать намеренно карикатурных пропорций:

```text
adult woman, balanced proportions, natural body proportions
```

Для более стройного силуэта можно проверить:

```text
slim body, natural proportions
```

Для более мягкого и округлого силуэта:

```text
curvy, natural body proportions
```

`balanced proportions` и `natural body proportions` — описательные подсказки, а не единый стандарт «правильного» тела. В теговых моделях на результат сильнее могут влиять конкретные слова формы, поза, одежда и стиль.

### 14.2. Рост и общий силуэт

| Что нужно | Теги для теста | Важно |
|---|---|---|
| Высокая фигура | `tall female`, `long legs` | Длинные ноги могут визуально менять весь силуэт |
| Невысокая взрослая фигура | `short female`, `adult woman` | Следи, чтобы образ не стал чиби |
| Стройная фигура | `slim`, `slender body` | Может уменьшать объём бёдер и груди |
| Обычное / среднее телосложение | `average body`, `natural proportions` | Описательные варианты, могут срабатывать слабо |
| Спортивная фигура | `athletic`, `toned body` | Может подчеркнуть мышцы |
| Мягкие округлые формы | `curvy`, `soft body` | Иногда заметно увеличивает грудь и бёдра |
| Пышная фигура | `voluptuous` | Может дать очень выраженные формы |
| Худощавая фигура | `thin`, `slim` | Не сочетай автоматически с `curvy` |
| Широкие плечи | `broad shoulders` | Может сделать верх тела массивнее |
| Узкие плечи | `narrow shoulders` | Описательное уточнение |
| Длинный торс | `long torso` | Экспериментальная описательная фраза |
| Короткий торс | `short torso` | Экспериментальная описательная фраза |

**Базовое правило:** если хочешь только длиннее ноги, добавь `long legs`, а не целый список тегов про рост, стройность и форму тела одновременно.

### 14.3. Грудь: плоская, маленькая, средняя, большая

| Желаемый размер | Positive-тег | Комментарий |
|---|---|---|
| Плоская грудь | `flat chest` | Самый явный вариант для почти плоского силуэта |
| Маленькая грудь | `small breasts` | Умеренно небольшой объём |
| Средняя грудь | `medium breasts` | Подходящий первый тест для среднего размера |
| Большая грудь | `large breasts` | Заметно увеличенный объём |
| Очень большая грудь | `huge breasts` | Часто даёт преувеличенный аниме-силуэт |
| Естественная форма | `natural breasts` | Может помогать, но не гарантирует реалистичную анатомию |
| Высокая посадка / поддержка одеждой | `supportive clothing` | Общее описание одежды, эффект зависит от наряда |
| Выраженное декольте | `cleavage` | Описывает видимую линию декольте, не точный размер |

Тестируй один размер за раз. Например:

```text
adult woman, medium breasts, balanced proportions
```

Если одновременно добавить `large breasts`, `huge breasts` и `small breasts`, модель получит конфликтующие подсказки. Не нужно перечислять противоположные размеры в negative: укажи один желаемый вариант в positive.

### 14.4. Талия, живот, бёдра и ягодицы

| Что нужно | Тег / сочетание | Комментарий |
|---|---|---|
| Узкая талия | `narrow waist` | Подчёркивает сужение талии |
| Обычная / мягкая талия | `natural waist` | Описательное уточнение |
| Широкие бёдра | `wide hips` | Увеличивает ширину нижней части силуэта |
| Узкие бёдра | `narrow hips` | Может сделать силуэт более прямым |
| Округлые бёдра | `curvy hips` | Описательная фраза, тестируй отдельно |
| Толстые / объёмные бёдра | `thick thighs` | Распространённый тег формы ног |
| Стройные бёдра | `slim thighs` | Описательное уточнение |
| Мускулистые ноги | `muscular legs` | Может заметно увеличить объём мышц |
| Плоский живот | `flat stomach` | Подчёркивает ровный живот |
| Видимый пресс | `abs` | Может сделать фигуру спортивной |
| Мягкий живот | `soft belly` | Описательное уточнение |
| Выраженные ягодицы | `wide hips` плюс описание позы | Теги ягодиц могут быть непредсказуемы; проверь ракурс |

Пример сбалансированного силуэта с выраженной талией:

```text
adult woman, balanced proportions, narrow waist, medium breasts, natural body proportions
```

### 14.5. Ноги, руки, кисти и ступни: относительные размеры

| Что нужно | Тег / сочетание | Примечание |
|---|---|---|
| Длинные ноги | `long legs` | Может визуально увеличить рост |
| Короткие ноги | `short legs` | Описательное уточнение |
| Стройные ноги | `slim legs` | Может уменьшить объём бёдер |
| Мускулистые ноги | `muscular legs` | Спортивный силуэт |
| Толстые бёдра | `thick thighs` | Относится к верхней части ног |
| Длинные руки | `long arms` | Может работать неустойчиво |
| Мускулистые руки | `muscular arms` | Подчёркивает мышцы |
| Маленькие кисти | `small hands` | Иногда уменьшает кисть слишком сильно |
| Крупные кисти | `large hands` | Может влиять и на пропорции пальцев |
| Маленькие стопы | `small feet` | Слабее работает, если стопы не видны |
| Большие стопы | `large feet` | Может преувеличивать размер обуви |

Не добавляй `small hands` только потому, что пальцы плохо нарисованы: размер кисти и качество анатомии — разные задачи. Для ошибок пальцев лучше использовать отдельный negative и при необходимости inpainting.

### 14.6. Нос: маленький, средний, крупный, длинный

| Что нужно | Тег / сочетание | Примечание |
|---|---|---|
| Маленький нос | `small nose` | Может сделать нос почти незаметным в аниме-стиле |
| Средний / нейтральный нос | `medium-sized nose` | Описательная фраза; может сработать слабо |
| Крупный нос | `large nose` | Может дать очень заметный нос |
| Длинный нос | `long nose` | Может менять профиль и лицо в целом |
| Короткий нос | `short nose` | Описательное уточнение |
| Выраженная переносица | `defined nose bridge` | Экспериментальная описательная фраза |
| Нос с мягкими чертами | `soft facial features, small nose` | Сочетание может усилить миловидность |
| Более взрослые черты лица | `mature face, defined jawline` | Не является тегом размера носа |

Для нейтрального результата часто лучше **не задавать размер носа вообще**. В аниме-стиле нос может зависеть от художественного стиля сильнее, чем от описательного тега. Если хочешь проверить средний размер, тестируй только `medium-sized nose` на фиксированном seed и сравнивай с вариантом без этого тега.

## 15. Одежда поверх одежды: слои, перекрытие и видимое бельё

Когда модель рисует нижнее бельё поверх платья, она часто воспринимает тег видимого белья как отдельный важный объект и неправильно строит визуальный порядок слоёв. Промпт должен описывать не только предметы одежды, но и **что находится сверху, что под ним и какая часть действительно видна**.

### 15.1. Сначала назови слои в правильном порядке

Для обычного одетого персонажа используй принцип:

1. **Внешний слой:** платье, юбка, пальто, куртка.
2. **Внутренний слой:** рубашка, топ, нижнее бельё.
3. **Видимая часть:** только край, полоска или участок, который должен быть виден.

Пример для платья поверх нижнего белья:

```text
dress worn over underwear, panties underneath dress, layered clothing
```

Это описательное сочетание, не специальная команда глубины. Но оно задаёт отношения между вещами лучше, чем просто перечисление `dress, panties`.

### 15.2. Если бельё должно быть слегка видно под краем платья

Positive для теста:

```text
adult woman, dress worn over panties, panties underneath dress, dress hem overlapping underwear, layered clothing
```

Если нужно показать только небольшой край, попробуй добавить:

```text
subtle visible waistband, partially visible underwear beneath dress
```

Эти фразы описательные и могут работать неустойчиво. Если модель всё равно рисует бельё поверх ткани, убери слово `panties` из основного промпта на первом тесте и опиши только видимый край в локальном inpainting.

### 15.3. Если платье должно закрывать бельё полностью

Positive:

```text
dress fully covering underwear, layered clothing, opaque fabric
```

Negative, если бельё неожиданно появляется поверх платья:

```text
underwear over clothes, panties over dress, clothing overlap, misplaced clothing
```

Negative-теги вроде `clothing overlap` — описательные эксперименты, а не гарантированные обучающие теги. Используй их только если видишь именно эту ошибку.

### 15.4. Если наружная одежда должна быть поверх внутренней

**Рубашка под курткой:**
```text
shirt under jacket, jacket worn over shirt, layered clothing
```

**Топ под расстёгнутой курткой:**
```text
top under open jacket, jacket worn over top, layered clothing
```

**Юбка поверх колготок:**
```text
skirt worn over tights, tights underneath skirt, layered clothing
```

**Платье поверх нижней комбинации:**
```text
dress worn over slip, slip underneath dress, layered clothing
```

Повторение отношений `X over Y` и `Y underneath X` иногда помогает, но не гарантирует правильную геометрию ткани.

### 15.5. Не смешивай «слой одежды» и «часть, которая видна»

Плохо для точного контроля:

```text
dress, panties, underwear, skirt, clothes
```

Так модель получает набор объектов, но почти не получает информацию об их взаимном расположении.

Лучше для теста:

```text
dress worn over underwear, panties underneath dress, layered clothing
```

Если нужна только небольшая видимая деталь:

```text
dress worn over underwear, partially visible waistband beneath dress
```

### 15.6. Что добавить в Negative

Если бельё рисуется поверх платья, проверь короткий negative:

```text
underwear over clothes, panties over dress, misplaced clothing
```

Если появляются несколько несовместимых слоёв:

```text
duplicated clothing, overlapping garments, misplaced clothing
```

Это описательные фразы и могут не распознаваться моделью как устойчивые теги. Не вставляй оба блока автоматически: сначала проверь, какой именно дефект возникает.

### 15.7. Самый надёжный способ исправить уже готовую картинку

Если всё изображение хорошее, а порядок одежды испорчен, не перестраивай весь промпт:

1. Открой изображение в inpainting.
2. Замаскируй только участок, где ткань и бельё перепутались.
3. В positive опиши внешний слой и его положение: `dress fabric in foreground, dress worn over underwear, layered clothing`.
4. В negative добавь только наблюдаемую ошибку, например `panties over dress, misplaced clothing`.
5. Сохрани тот же стиль и не меняй лицо, позу или фон.
6. Если маска захватывает слишком большую область, модель может перерисовать весь наряд; начни с небольшой маски и расширяй её постепенно.

**Важно:** для модели слово «видно» не всегда означает «находится под тканью». Уточняй слой, перекрытие и видимую часть отдельно. Если геометрия одежды сложная, inpainting или контроль позы обычно полезнее, чем длинный общий negative prompt.
