# Forge Model Style Pattern

Практическая база знаний по **Stable Diffusion WebUI Forge** и чекпойнту **WAI Illustrious SDXL v1.7** (`waiIllustriousSDXL_v170.safetensors`).

Цель — не просто копировать промпты, а понимать, **какое видимое изменение обычно связано с каждым тегом**, как проверить это в Forge и как постепенно собрать устойчивый личный стиль.

> Важно: тег не является гарантированной командой. Он подсказывает модели визуальные закономерности, усвоенные во время обучения. Один тег может работать по-разному в зависимости от модели, остальных тегов, порядка, веса, seed и настроек.

## Быстрый старт

- Checkpoint: `waiIllustriousSDXL_v170.safetensors`
- Sampler: `Euler a`
- Steps: `25`
- CFG: `6`
- Seed: фиксированный, не `-1`
- Hires.fix: выключен на время изучения тегов
- Размер: например, `832 × 1216` для портрета; сравнивай в одном и том же разрешении.

Это отправная точка для тестирования, а не единственно правильные настройки. Для WAI v17.0 опубликованные рекомендации указывают примерно 25–40 шагов и CFG 5–7.

Базовый позитивный блок:

```text
masterpiece, best quality, amazing quality
```

Короткий негативный блок, встречающийся в рекомендациях для WAI v1.7:

```text
bad quality, worst quality, worst detail, sketch, censor
```

Не добавляй десятки отрицаний автоматически: добавляй их, когда видишь конкретную проблему.

## Как устроен каждый термин

- **Тег** — точное английское написание для теста.
- **Буквальный смысл** — разбор слов, когда он помогает запомнить.
- **Что искать глазами** — наблюдаемый признак на готовой картинке.
- **Ожидаемый эффект** — вероятное направление, а не гарантия.
- **Побочные эффекты** — что ещё может измениться.
- **Уверенность** — практическая оценка предсказуемости, а не опубликованный лабораторный рейтинг.

## Принцип проекта

**Не учи 200 тегов наизусть. Учись распознавать одно видимое отличие за раз.** Сначала сравниваем, затем запоминаем слово, затем решаем, нужно ли оно личному стилю.
